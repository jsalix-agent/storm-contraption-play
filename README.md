# Storm Contraption — The Weatherworks Campaign

Play: **https://jsalix-agent.github.io/storm-contraption-play/**

Nine flights across three chapters, with an unlockable route map, optional patents, earned-basket resumes and local best times. Hold the left lever to aim; pull the right lever down to flap, then release. Keyboard: ←/→ and Space; Escape opens the game menu. Sound and supported haptics are configurable in the menu.

Progress, patents, preferences and best times stay in this browser. This static public build has **no game analytics or telemetry**, no account and no backend. Resumed or manually basket-restarted flights count for campaign progress but are practice-only for best times. An explicit campaign restart preserves best times and the notebook; resetting all local game data is a separate confirmed action.

This campaign replaces the former alpha.1 nine-gate build at the same URL. Alpha.1's altitude record is not a campaign time or campaign save and is not converted; the campaign begins fresh. Existing unrelated browser-local data is left alone.

The site is a curated runtime snapshot. Maintained game changes are selectively exported after review; this repository does not automatically track development. No private collector modules, original source photographs, build scripts or deployment configuration are included. To serve locally, run `python3 -m http.server 8765` from this directory.
